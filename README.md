# Browser Homepage

A small personal project I made because I am a big fan of **web browsers** and customization.

At the time, I could not find a browser homepage that really matched what I wanted, so I decided to build my own.

The goal was simply to create a clean and personalized start page with quick access to the things I use most, helping me save a bit of time every day.
